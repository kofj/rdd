### Stage 3: 上下文恢复增强 ⏳

**目标**: 实现 Compact 后的自动上下文恢复能力

**核心假设**:
- Agent 在 Compact 后可以检测到恢复需求
- Handoff 文档包含足够的上下文信息
- 状态持久化可以保存工作进度

**验收标准**:
- [ ] 自动 Handoff 生成机制实现
  - Gate 完成后自动生成
  - 重要决策后自动更新
  - 30分钟无进展触发
- [ ] 状态持久化实现
  - `.rdd/cache/checkpoints.json` 格式定义
  - Gate 进度保存
  - 阻塞项保存
  - 状态恢复功能
- [ ] Compact 恢复协议实现
  - CLAUDE.md 会话启动协议
  - 自动检测恢复场景
  - 自动加载 handoff 和 checkpoint
- [ ] 恢复流程 E2E 测试通过
- [ ] fresh-agent-check 自动化测试通过

**依赖**: Stage 2 完成

**技术债解决**: TD-08, TD-10

**回滚计划**: 功能独立，可禁用自动恢复

**状态**: ⏳ 待开始
