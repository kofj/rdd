## E2E 测试架构

### 测试环境

```
┌─────────────────────────────────────────────────────────────┐
│                    Docker Test Container                      │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐          │
│  │ Claude Code │  │ RDD Skills  │  │ Test Project│          │
│  │ (CLI)       │  │ & Commands  │  │ (minimal)   │          │
│  └─────────────┘  └─────────────┘  └─────────────┘          │
│                                                              │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              Third-Party Model API                   │    │
│  │              (通过环境变量配置)                        │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

### 敏感信息处理

**禁止写入文件**:
- API Token
- API URL (非公开)
- 认证信息

**正确做法**: 通过环境变量传递敏感配置
